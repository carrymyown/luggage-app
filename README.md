# 行李規劃

手機瀏覽器用的行李重量規劃小工具，介面為繁體中文。純 HTML／CSS／JavaScript，不需後端，資料存在瀏覽器的 localStorage。

## 網址

https://carrymyown.github.io/luggage-app/

推送到 `main` 分支後，GitHub Actions 會自動發布到 GitHub Pages（設定檔在 `.github/workflows/pages.yml`）。

## 功能（第一版）

- **沒有登入時**：一律顯示虛擬範例資料（台北・東京的公寓・首爾那一套），最上方有「現在是範例資料・登入開始使用」。範例只在這台裝置，不會上傳。你自己的資料只有登入後才會顯示。
- **第一次使用**：新帳號第一次登入、雲端沒有資料時，會出現第一次使用設定（名字、自己的家、常用航空公司與額度、常用行李箱，每一步都能跳過）。
- **登出**：先確認資料和照片都已同步到雲端；還有沒同步的會讓你選「先同步」或「取消登出」。確認後清掉這台裝置上的個人資料（localStorage）、照片暫存（IndexedDB）和範例，雲端資料保留，畫面改成範例。重新登入會從雲端把資料和照片載回來，範例不會混進去也不會上傳。
- **新版本提示**：每次打開或回到前景時檢查 `version.json`，有新版就在下方顯示「有新版本・點一下更新」（只更新程式檔案，不動資料）。帳號選單最下面顯示目前的版本號碼。
- **試用範例**：範例資料（台北・東京兩個家、台北→東京→首爾→大阪→台北的旅程、衣櫃、抽屜、行李箱、打包清單、購物與禮物、每日穿搭）只存在這台裝置的另一個位置，不會同步到雲端，也不會跟自己的資料混在一起。範例模式最上方有提示列，「清除範例，開始使用」會刪掉所有範例並進入第一次使用設定；帳號選單的「再看一次範例」隨時可以再看，不影響自己的資料。範例模式中有六個黑底提示卡，依序是首頁的剩餘公斤數、行程的航班額度、行程的每天穿搭小方格、中間的＋、打包、家（衣櫃、抽屜、行李箱）；每則都有「上一個」「下一個」，頁數照實際數量顯示，等畫面和按鈕位置穩定了才顯示；按「下一個」「上一個」會自動切到那一頁、捲到被說明的地方，最後一則按「開始使用」回到首頁，一步一步說明。範例內容集中在 `sample-data.js`，而且是用各功能自己的新增函式產生，跟正式資料格式完全一樣。修改功能時要一起更新範例，規則寫在 `CLAUDE.md`。
- **家**：每個帳號自己的清單，在右上角帳號選單 → 名字與頭像裡新增、改名、改所在城市、刪除。家的名字可以自由取（例如「我的公寓」「爸媽家」），判斷抵達哪個家、整理行李、行程標示「有家」一律用**所在城市**比對。
- **刪除旅程**：確認視窗會列出這趟的購物、禮物、打包清單數量，並一起刪除；已經放進某個家的購物和禮物，物品會留在那個家。旅程已刪掉、看不到的舊資料會自動清理。
- **新增物品加入打包清單**：新增衣服或抽屜物品時，如果有下一趟旅程，可以勾「加入下一趟的打包清單」（預設不勾），會放在它預設的行李區。
- **首頁**：大字顯示「剩餘可購物公斤數」（各行李上限總和 − 目前總重）。
  剩餘 ≥ 20% 為綠色（充裕）、0–20% 為黃色（快滿了）、超過上限為紅色（超重）。
  下方顯示目前總重量、各行李重量與物品清單。
  「行李額度」可依每次航空公司的額度調整各行李上限（預設托運 23 kg、登機 7 kg）、空箱重與名稱。
- **放進行李**：名稱、重量（kg 或 g）、數量、單位（個／包）、品類、放在哪個行李。
  七大品類：①必備品 ②保健品 ③保養品 ④特殊類 ⑤禮物 ⑥食品 ⑦電線電器。
  新增過的物品會自動記住，之後在「常帶物品」點一下即可帶入；可按「管理」刪除記錄。
- **常見物品參考重量**：輸入名稱時，如果對到參考重量表，會自動帶入大約重量並標示「約」。
  改成實際秤到的重量後，會以你的數字為準並記進常帶物品。

- **物品照片**：「放進行李」可拍照或從相簿選照片（可略過）。照片縮到最長邊 600 像素、
  JPEG 品質 0.7（太大會再降），每張盡量在 100KB 內，存在瀏覽器的 IndexedDB（`photos.js`）。
- **衣服標籤**：品類是「必備品」時，可點選衣服種類（大類→細項）、顏色（深色／淺色／大地色；首飾、手錶、錶帶是金色、銀色等）、花紋、季節、場合（正式、休閒、運動、馬術，可複選；以前的「度假」自動改成休閒），品牌自行輸入（`clothing.js`）。資料裡保留詳細顏色給每日穿搭用。
  每件有照片或標籤的衣服都是獨立的常帶物品，常帶物品會顯示小縮圖。
- **衣櫃**：照片格子排列所有有標籤的衣服，五個分頁：衣服（再分全部、上衣、下身、洋裝、外套、睡衣）、鞋子、包包、配件（帽子、圍巾、首飾、皮帶、太陽眼鏡、手錶、錶帶）、貼身衣物；
  再依家、顏色（三種色系）、季節、場合篩選（每一排前面不放小標，排和排之間一條細線）。新增一律用下方的「＋」（`closet.js`）。行程有騎馬時，穿搭和打包優先用標「馬術」的衣物；沒有騎馬時只標馬術的不會自動帶。

- **行程**：建立旅程（名稱、出發地），每趟可加多段航班（出發／抵達城市、日期、航班號碼、航空公司），
  每段有自己的托運、手提、背包額度；可編輯、刪除、調整順序。抵達有家的城市會標示「有家」（`trips.js`）。
  首頁的剩餘公斤數依「今天以後最近的一段航班」的額度計算，沒有行程時用「行李額度」的設定。
- **轉機資訊**：每段航班有起飛／抵達日期與時間（當地，點選 24 小時制時間選擇器），兩段之間自動算出轉機時間（跨日也正確）；
  每個轉機點可設定行李「直掛／領出」與「不入境轉機／入境停留」（可填停留天數、備註），列表以小標籤顯示。
- **物品位置**：衣物的位置分為「在某個家／在行李裡（記得行李箱與從哪個家帶出）／待確認」，並保留移動紀錄。
  行程抵達有家的城市（或旅程結束回家）時跳出「整理行李」，決定留下或帶走、從這個家的衣櫃挑東西帶走（`organize.js`）。
  衣櫃可手動「移到另一個家」，家的篩選有「在行李裡」分頁。
- **首頁**：最上方是旅程卡（剩餘公斤數、「預留空間 已用 X / Y kg ›」、今天的穿搭），打包清單的必帶、上衣、下身、鞋子、首飾盒、貼身衣物、保養品一直顯示（沒有東西時下方灰字「還沒加，點這裡從衣櫃挑／從抽屜挑」，點了直接打開挑選畫面），洋裝、外套、睡衣、包包、配件、保健品、電線電器、特殊類、食品、禮物、其他有東西才顯示。右上角帳號圖示顯示自己的小頭像（`profile.js`：上傳的照片，沒有照片時是名字第一個字的圓形頭像；名字和頭像存到雲端，換裝置也一樣）。帳號選單只有：名字與頭像、語言 / Language、匯出備份／匯入備份（一行小字）、再看一次範例、再看一次介紹、登出（只問一次「要登出嗎？」）；沒登入時最上方是「登入」按鈕，按了才展開 Email 和密碼。行李箱設定在「家 → 行李箱」。
- **打包頁**：最上方直接是兩個平行分頁（只顯示文字，不放數字）「清單 LIST」（依品項分組，去哪裡拿）和「行李 BAGS」（依隨身小包、背包、手提、托運分組，放進哪個箱子），下面整趟的剩餘公斤數進度條。清單的組別依序是必帶、上衣、下身、洋裝／連身、外套、睡衣、鞋子、帽子／圍巾、首飾配件、保養品、保健品、電線電器、特殊類、食品、禮物、其他（沒有東西的不顯示；必帶清單裡的只在「必帶」），每組標題顯示「2 / 4」，整組打勾完成出現小勾、自動收起（點標題可以展開或收合），每一項右邊一個小灰標籤寫放進哪個行李（點了可以改）；出發前檢查會特別提醒「必帶」還沒打勾的。打勾＝放進行李，重量立刻扣掉，和首頁同一個數字。
- **行李進度條**：每個行李、打包頁整趟、首頁行李區塊共用同一條 6px 方角進度條：已放近黑、還能放霧感天空藍、剩不到 15% 芥末黃、超重整條酒紅，右邊「7 / 23 kg」，快滿、超重另外寫小字；寬度變化約 0.2 秒（減少動態效果時不動）。除了進度條，全 app 只用黑、白、灰（中間的＋也是黑底白＋號）。
- **清單刪除與修改**：往左滑出現「刪除」、長按跳出「修改」「刪除」、點一下打開修改（名稱、重量、數量、放哪個行李）；分頁列右上角的小字「編輯」可以一次刪很多項、拖曳調整順序。「清單」分頁只有一個新增按鈕「＋ 加到清單」（從衣櫃、抽屜挑或直接輸入）；「行李」分頁每個行李下方有「＋ 放進這個行李」，挑的東西直接放進那個行李。刪除只代表這趟不帶（衣櫃、抽屜、必帶清單都不變），畫面下方「已移除・復原」幾秒內可以復原。衣櫃、抽屜裡的東西改名稱或重量會一起更新（同一樣東西只有一個重量）。
- **中間的「＋」**：標題「新增到」，四個選項：衣櫃（衣服、鞋子、帽子和配件）、抽屜（保養品、電線這些出門會帶的東西）、購物（旅途中買給自己的）、禮物（要帶去送人的）。新增行李箱在「家 → 行李箱」。
- **這趟的穿搭**：打開一趟旅程（編輯旅程）時最上方有「這趟的穿搭 ›」，點了看每一天的搭配。
- **貼身衣物**（家 → 衣櫃 → 貼身衣物，`intimates.js`）：襪子、內衣褲只記數量、不用照片，依家分開記（加減按鈕），每項有每雙／每件的參考重量，可以改名稱、新增項目。打包時依住幾晚建議數量（冷的地方保暖長襪、熱的地方短襪、有運動行程加運動內衣），目的地的家已經有的會扣掉並顯示「東京的家有 3 雙」；清單裡放在「貼身衣物」組，打勾＝放進行李（那個家的數量跟著減少）。免洗內褲標記「用完就丟」：旅程中每過一天扣掉一件，行李變輕，用完的不會回到任何一個家。必帶清單的「內衣褲」「襪子」改成連到這裡，不會重複出現。
- **消耗品用量、當地買或自己帶**（`consumables.js`）：只有會用完的東西（保養品、洗漱用品、保健品、食品）顯示和記錄「剩多少」，護照、錢包、電線、特殊類、禮物都不顯示（已存的資料保留）；新增和編輯時是一行四格：滿、一半、快用完、沒了，每個家各自記。離開一個家時（整理行李畫面、出發前檢查）有「快速檢查」，一頁列出這個家的保養品、洗漱用品、保健品、食品，點一下更新，可以全部略過。某個家的消耗品快用完或沒了，下一趟會抵達那個家時首頁出現補貨提醒（例如「台北的家洗面乳快用完了」）：在上一個城市買好帶過去（加進購物清單，預估重量算進預留空間，抵達時自動補成「滿」）、網購寄到家（不算行李重量，抵達前 5 天提醒下單，可以打勾已訂）、不用提醒。打包頁第一次遇到沒有家、還沒標記的住宿城市會問一次「當地好買保養品和洗漱用品嗎？」，之後記住（依國家），行程裡可以改；這趟沒有家的城市都好買 → 保養品和洗漱用品建議到當地買（打包清單下方變灰，顯示省下多少，可以拉回要帶），有不好買的 → 依沒有家的晚數建議旅行分裝的份量；打包頁顯示「到當地買、家裡已經有」一共省下多少公斤。
- **語言 / Language**：帳號選單可以切換繁體中文和 English，立刻生效。語言記在這台裝置，登入時也存到雲端（`prefs.lang`），換裝置也一樣；第一次打開依裝置語言（中文→繁體中文，其他→English）。翻譯在 `lang.js`、切換在 `i18n.js`；範例資料的英文名稱在 `sample-data.js` 的 `EN_NAMES`。
- **頁首**：每一頁頁首只有「CARRY MY OWN」和帳號圖示，不再放「打包」「行程」「家」這類大標題（底部導覽已經顯示在哪一頁）。
- **名稱**：首頁 HOME、行程 TRIPS、打包 PACKING（清單 LIST／行李 BAGS）、家 HOMES（衣櫃 WARDROBE／抽屜 DRAWER／行李箱 LUGGAGE）、首頁行李區塊 BAGS、剩餘公斤數 REMAINING、購物 SHOPPING、送禮 GIFTS、穿搭 OUTFITS。
- **打包清單**：選一趟旅程自動產生清單（依行程頁設定的季節、活動和常帶物品；行程改了會自動補上，並固定提醒護照、錢包、充電線、睡衣），
  分手提／托運／背包三區，可打勾、拖曳換區、刪除、手動新增；顯示進度與各區重量對比額度；
  目的地的家已有的物品列在「家裡已經有，不用帶」；有「出發前檢查」。打勾＝放進行李，首頁重量同步（`packing.js`）。
- **抽屜**：衣服以外的物品（必備品、保健品、保養品、特殊類、禮物、食品、電線電器），依家切換、依品類分組，
  數量用加減按鈕或「有／快用完／沒了」；快速新增會帶入參考重量與品類，同一個家已有同名物品會提醒。
  抽屜物品和衣物一樣有位置（在某個家／在行李裡／待確認），整理行李畫面也包含抽屜物品（`drawer.js`）。
- **每日穿搭**（行程 → 點一趟旅程，`outfit.js`）：列出旅程的每一天（日期、所在城市、天氣最高／最低溫與會不會下雨、當天活動）。
  天氣來自 Open-Meteo（免費、不需要金鑰）：16 天內用預報，更遠用往年同期平均（標示「往年平均」），沒網路時用上次抓到的（存在 `cmo-weather`）。
  活動可複選（日常逛街、正式場合、長途飛行、騎馬、網球、運動、海邊、登山，也能自己新增）。點某一天＝雜誌平拍式的穿搭：
  上衣在上、下身在下（洋裝取代兩者）、外套在旁邊、鞋子在下面、配件在一側；每個部位可左右滑動換一件、鎖頭固定；
  「確定這套」把用到的衣服加進打包清單（不重複）、「換一套」重新搭。自動搭配用標籤判斷：氣溫選厚薄、約 15°C 以下一定有外套、
  下雨避開不適合的鞋子、活動（騎馬、網球、正式場合、長途飛行…）、花紋配素色、配件金銀色統一、優先用這趟清單上的衣服並重複使用、
  相鄰兩天上衣不同；所在城市有家的話，那個家衣櫃裡的也能穿（標示「在東京的家」、不用帶）；睡衣不參與。
  每一天右邊有一個 44×44 的小方格：按過「確定這套」的那天顯示穿搭縮圖，還沒搭的是虛線框＋「＋」，下面「穿搭 ›」，點了進那天的穿搭頁；
  首頁旅程卡在今天或明天在旅程裡時，多一行「今天的穿搭 ›」（或「明天的穿搭 ›」）。
  標題是旅程名稱和日期（例如「台灣投票・11/20–11/26」）。上面是每一天的穿搭，接著是「這 X 件衣服，可以搭出 Y 套」，
  最下面是「沒穿到，可以不帶」：每一天都按過「確定這套」之後，列出已經打包但穿搭都沒用到的衣服（小縮圖＋「不帶」按鈕，按了從打包清單移除，
  公斤數立刻更新）；還有日子沒搭時只顯示「還有 X 天沒搭，搭完再告訴你哪些可以不帶」。某一天按「確定」後存好並回到進來前的那一頁，
  下方顯示「已更新穿搭」，那一天的小方格立刻換成新的縮圖；存不進去就留在原地顯示錯誤。每天的選擇存在 `dayPlans`，跟著雲端同步。
  行程列表每張旅程卡整張可以點，右邊細線小箭頭「›」，日期下方一行摘要「3 段航班・穿搭 2/5」（還沒有穿搭只顯示航班數）。
- **年度行事曆**：行程頁可切換「列表／月曆／年度時間軸」。月曆與年度色條顯示每趟旅程的日期區間；
  兩趟之間的空檔顯示回到哪個家、待幾天。每趟可設定「最後一段結束後回到哪個家」，新增下一趟時預設從那個家出發。

- **行李箱**（家 → 行李箱，每個家可以新增）：名稱、類型（隨身小包／背包／手提／托運）、尺寸、款式、材質（可「新增」自己的選項，長按刪除）、
  空箱重量、放在哪個家、照片。每趟每種行李用哪個箱子，在首頁「行李 → 選擇行李箱」或打包清單上方選（兩邊同一份）；
  還沒選時顯示「尚未選擇行李箱」、空箱算 0；可以選「這趟不帶」。額度一律讀行程裡下一段航班，沒填就顯示「尚未設定額度」。
  隨身小包的重量預設算進背包／個人物品額度，可在行程裡改成單獨計算或不計算（`bags.js`、`packing.js`）。
- **回程購物・送禮**（首頁旅程卡下方、或「＋」→ 記一筆購物）：上方兩個分頁：購物（自己買、自己留的東西）和送禮（要送人的東西）。記錄買了什麼和重量，從剩餘公斤數扣掉；買之前可以先試算。旅程卡上可以設定「預留空間」（這趟想留給購物和送禮的公斤數，可不設），卡片顯示「預留空間 已用 X / Y kg」（行李裡的購物和禮物都算），點了進這趟的購物和送禮頁；打包快用到這個空間時會提醒。
  記錄購物（名稱、重量、數量、價格、放進哪個行李、在哪個城市買、之後放到哪個家、照片；抵達那個家時出現在整理行李畫面）；計畫清單打勾就記成已買。
  送禮：送給誰、在哪個城市送、想買／已買好／在行李裡／已送出，可從抽屜「禮物」品類挑；想買的禮物重量預留在計畫購物；
  抵達那個城市時首頁提醒「這裡有 X 份禮物要送」；可依送禮對象查看紀錄。放進行李的購物和禮物會算進首頁剩餘公斤數（`shop.js`）。
首頁「備份與雲端同步」可匯出／匯入備份檔（含所有資料與照片）（`backup.js`）。
- **雲端同步（Supabase）**：Email＋密碼登入；資料存在 `app_state` 資料表（每人一筆），照片存在 Storage 的 `photos`
  bucket（`<帳號 id>/<照片 id>.jpg`），以 Row Level Security 限制只能存取自己的資料（`cloud.js`）。
  資料先存在本機，有網路時自動同步；兩台裝置都改過時以上次同步內容為基準逐筆合併。
  程式只使用 publishable（公開）金鑰，不含 service_role 金鑰。Supabase 程式庫放在 `vendor/supabase.js`（v2.117.3）。
- **離線使用**：`sw.js`（Service Worker）快取 app 檔案，沒有網路也能打開。

## 資料結構

說明寫在 `app.js` 開頭。重點：
- `memory`（常帶物品）是「我擁有的東西」，每筆有 `photoId`、`clothing`（衣服標籤），
  並預留 `cloudId`、`syncedAt`（雲端儲存）與 `ai`（AI 辨識結果）。
- `clothing.part` 是穿搭部位（top、bottom、full、outer、shoes、accessory）；`outfits` 是預留的穿搭清單。
- `dayPlans`（每日穿搭）：`{ 旅程 id: { 日期: { acts, picks, locks, seed, confirmed } } }`，旅程刪掉時一起清掉。
- 上一版衣櫃資料會自動轉進 `memory`，原始資料保留在 `legacyWardrobe`。
- `trips`（旅程）與航班段 `legs`，預留匯入訂位紀錄（`source`、`importRef`、`bookingCode`）、
  AI 辨識行程單（`ai`）與多人共用（`ownerId`、`members`、`shareCode`）的欄位。
- 行李的 `kind`（托運、手提、背包）對應航班的三種額度。

## 參考重量表

放在 `weights.js`。檔案開頭有格式說明，照著複製一行修改即可增加項目。
- **外觀**：黑白精品風。純白底、近黑文字和線條；深海軍藍只用在選中的狀態，香檳金只留在中間的＋。標題和數字用粗的無襯線字 Archivo（等寬數字），中文用思源黑體；英文標題、選單、按鈕全大寫加寬字距。方角、不用圓角陰影漸層，用粗細兩種黑色直線分隔。剩餘公斤數的綠黃紅只用小圓點。衣櫃大圖格子（手機 2 張、iPad 3 張），照片下只有一行粗體品類名稱。動畫約 0.2 秒，開啟「減少動態效果」時關閉。
- **打包（兩個分頁）**：「要帶什麼」列出這趟還沒放進去的東西，每項自動帶入預設的行李、可以改（選單上顯示每個行李還能放多少，會超重就先提醒）；打勾＝放進去，移到「行李箱」。「行李箱」依隨身小包、背包、手提、托運分組，標題旁顯示「這個箱子還能放 X kg」（快滿變黃、超重變紅），可以拖到別的箱子或取消打勾。最上方是整趟的還能放，和首頁一致。
- **必帶清單**：「忘了會出問題、當地也買不到」的東西，預設是護照、簽證／入境文件、錢包、信用卡、現金、手機、充電線、處方藥、家裡的鑰匙（以前預設的行動電源、耳機、轉接頭、牙刷、睡衣、內衣褲、襪子、常備藥、基本保養品會自動移出，回到各自的分類；內衣褲、襪子由貼身衣物依天數建議）。打包頁「必帶」組標題旁邊的小字「編輯」，可以增加、刪除、改預設行李；每次產生新的打包清單時自動加進「要帶什麼」，出發前檢查會特別提醒還沒放進去的。
- **購物和送禮**：購物頁上方只有「購物」「送禮」兩個分頁，記一筆購物不再問用途。以前標「送人」的本來就是送禮分頁裡的禮物；以前標「自己帶」「紀念品」的都是一般購物（紀念品不再自動拿出行李，到家時在整理行李畫面決定）。禮物按「已送出」後從行李和打包清單拿掉、重量加回，只在送禮紀錄留一行，可以刪除。
- **歡迎頁**：第一次打開、還沒登入時出現四張意象畫面（不超重／不重複帶／少帶衣服多搭配／輕裝優雅），可以左右滑、右上角略過；最後一頁「開始使用」（登入→第一次使用設定）或「先看範例」。看過一次就不再自動出現，帳號選單有「再看一次介紹」。插畫是 `intro.js` 裡自己畫的 SVG（線條 1.5px、只用黑白和 #F4F4F4）。

## 保護雲端資料（2026-11-19）
- 同步一定先讀雲端，讀成功之後才可能上傳；照片也是讀完雲端才上傳。
- 這台裝置的資料是空的、讀不懂、或是範例資料時，絕對不上傳，改用雲端的資料。讀不懂的本機資料另外留在 `cmo-rescue-unreadable-<時間>`（登出也不會清掉）。
- 這次上傳會讓雲端的物品、旅程或整體資料少一半以上時，先跳出確認；雲端比這台少很多時（可能被別的裝置蓋掉），也先問要不要用這台的資料還原雲端。被換掉的那一份留在 `cmo-rescue-local-<時間>`。
- 之前的版本：在 Supabase 執行 `supabase/history.sql` 後，每次更新雲端前會自動把上一版存到 `app_state_history`（每個帳號保留 50 版）。帳號選單備份旁的「還原到之前的版本」可以選時間還原。
